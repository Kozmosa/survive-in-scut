# 创业指北

> 我们不必把人生的全部可能性，压缩进几条早已被规划好的轨道。

假如某天你突然萌生了一个想法：**我想创办一家像宇树科技、Kimi那样的科技公司。**

那么第一个现实问题就是：**我需要准备多少钱？**

100万？1000万？还是一个亿？

但你只是一个普通本科生，没有雄厚的家庭背景，没有认识的投资人，甚至连毕业后的工作都还没有着落，那么这样的想法是否从一开始就不切实际？

**这正是本文试图回答的问题。**

## 一、前言：我们所讨论的创业是什么？

提起创业，你可能首先想到开一家奶茶店、咖啡馆，或者经营校园零售、中介和电商业务。

当然，这些都是广泛意义上的创业。但本文想介绍的是另一种创业形式：硅谷式的**科技创业**。

以大疆为例：

汪滔从小就是一名航模爱好者，在香港科技大学读书期间，他的导师李泽湘支持他研发直升机飞行控制系统并将其作为自己的本科毕设。汪滔读研期间不断继续完善飞控技术，初期他通过航模爱好者论坛销售飞控设备。在发现这种盈利模式可行后，汪滔于 2006 年在深圳创办大疆；大疆初期并不顺利，整个公司半死不活，[将近分崩离析](https://bbs.dji.com/pro/detail?tid=54498)。李泽湘在这一时期从哈工深帮他引入大量技术人才重建大疆团队，还联系投资者寻找资金支持。大疆在李老师的资源扶持下活下来并且开始疯狂扩张，时至今日大疆已经成为无人机领域的绝对龙头企业，也是国内硅谷式科技创业最具代表性的成功案例之一。而汪滔本人身价也狂飙至**人民币350亿元**。

> 题外话：大疆后来还创办了面向全球青年工程师的**RoboMaster机甲大师赛**。我们学校的**华南虎战队**屡获殊荣🎆

此后，李泽湘进一步将多年积累的工程教育与创业实践经验系统化，先后推动创立XbotPark松山湖机器人基地、深圳科创学院，并将孵化生态拓展至重庆明月湖等地，尝试让更多年轻创业者获得人才、资金、实验室和产业链支持。

另一边，曾任雅虎、微软、百度高管的陆奇，于2018年创办并领导YC中国。2019年，随着Y Combinator退出中国市场，他带领原团队独立运营，创立了奇绩创坛，将硅谷式的早期投资与创业加速模式引入并适配中国市场。

李泽湘和陆奇二者为代表的科创体系也是当前笔者认为最完善的0-1孵化体系，同时也是笔者在下文详细讲解的两大科创体系。

首先声明：笔者并未参加过任何科创体系或孵化器，李泽湘是笔者的师爷，笔者对于李泽湘体系的了解仅仅局限于导师和笔者畅聊创业的那个遥远的下午，而笔者对于陆奇体系的了解也仅仅来源于与奇绩创坛某员工 coffee chat 的遥远的晚上，如有表达错误请多多海涵并联系笔者修改。

## 二、黑客松：本科生最容易接触的泛创业项目

### 2.1 什么是黑客松？

“黑客松”顾名思义即“黑客马拉松”，简单来说，就是一群人聚在一起，在非常短的时间内组队通过 vibe coding 等方式从零到一（当然并没有多少队伍从零到一，如今大部分的黑客松已经变成大家的队伍带着成熟的 idea 和完整的 GitHub 项目互相斗法了）把一个 idea 变成能够落地展示的软件或硬件产品，并在 demo day 向游客、投资人、评委展示自己的 idea 的落地可行性与盈利模式。具体的评分细则，笔者并不知晓，但笔者所参与的大部分黑客松都更看重“能否马上带来盈利，以及假如自己是受众，是否会愿意为了那个产品买单”。

典型流程大概是：

报名 → 筛选 → 组队 or solo → 数小时或数天开发项目 → 现场展示 → 评委评审。

笔者想强调的是：**黑客松的门槛可能比很多人想象中低得多。**

笔者参加过相当多的黑客松，见过不少连GitHub都不熟悉的参赛者，也与许多初中生高中生、中专、大专以及没有代码基础的文科生朋友一起开发过项目。对于E 人来说，黑客松也是非常不错的社交活动。可以在几天内认识不同背景、不同地区甚至不同国家的hacker。

> 并没有看不起中学生、专科生或文科生的意思，反而这类群体在笔者参与的大部分黑客松中才是获奖热门选手。

甚至还有一个最实际的好处：**某些大型黑客松会提供机酒补贴与三餐茶歇供应，这是一种能低成本到一座新城市旅行的机会。**笔者认为，毕竟黑客松本质上也是贩卖自己的三天脑力，假如一个比赛的主办方连食宿交通补贴分文不愿提供，那确实没有太大的参赛必要。

### 2.2 中国有哪些值得了解的黑客松？

这里挑选三个比较有代表性的活动。事实上，近年来各地各高校都在不断开展黑客松，黑客松并不像传统意义上的比赛，理论上我去博学楼预约 101 教室，在黑板上写上“华南理工黑客松”，再拉几个路过的同学一起参加，这也算是一种合法合规的“黑客松活动”。

25 年初秋时，字节跳动相关部门曾邀请笔者联系华工的相关协会一起开办校园黑客松，然而笔者放了他们鸽子，时至今日似乎他们部门仍然没能联系上其他社团部门负责人开展华南理工的校园黑客松，实在遗憾。26 年夏末，笔者的导师再次邀请笔者联合他们中山大学一起开展华工与中大两所高校的黑客松，笔者对之倍感期待，假如有合作方也对之抱有期待并愿意推动这一活动，请一定要联系笔者。

以下列举一些笔者印象中的大规模黑客松，小规模的黑客松如 WayToAGI 或hackthon weekly 就不在讨论范围内了。除了这三个笔者印象比较深刻的黑客松外，也有比如小米黑客松、知乎黑客松、贴吧黑客松等公司为主体的黑客松和大量如雨后春笋般出现的地名黑客松“X 客松”，这类黑客松通常能拿到数万、数十万的地方政府投资，如比较有代表性的南客松（南京）、贵客松（贵州）等等。

## 四、以李泽湘为代表的科创体系

### 4.1 李泽湘是谁？

李泽湘是**香港科技大学机器人与自动化领域的教授、博士生导师，XbotPark机器人基地创始人、深圳科创学院创始院长**，同时也是一位长期参与硬科技企业创办、投资与孵化的创业导师。

除前文提到的大疆外，他与学生及合作伙伴先后创办、投资或孵化了**固高科技、云鲸智能、正浩创新（EcoFlow）、海柔创新、逸动科技、希迪智驾**等知名企业。

根据深圳科创学院官网公布的数据，李泽湘的科创生态已累计孵化**265家以上硬科技企业**，其中包括上市公司和多家估值超过10亿美元的独角兽企业。

为了将高校里的技术项目转化为真正能够商业化的产品，他于2014年联合创办**XbotPark松山湖机器人基地**，并于2021年创立**深圳科创学院**，将创业人才培养、早期投资、产品研发和珠三角制造供应链整合起来，为年轻创业者提供系统化支持。

### 4.2 李泽湘体系并不只是一家孵化器

李老师在发现他的创业模式是科学成体系并且可复制的后，开始建立起自己的李泽湘体系并不断优化自己的创业理论：

[**深圳科创学院（深圳）**](https://www.innoxsz.com/)**：** 这是数个李泽湘体系的孵化器中笔者认为影响力最大的一个，它是李泽湘发起的科创教育与创业孵化机构，2021年成立。面向潜在创业者提供科创训练营、创业探索、产品开发、工程设施及早期项目孵化支持。

[**XbotPark松山湖机器人基地（东莞）**](https://www.xbotpark.com/)**：** 2014年由李泽湘联合高秉强、甘洁等人创立，是体系的重要发源地，主要面向机器人、智能硬件和其他硬科技团队，提供早期投资、导师、实验室及珠三角制造供应链资源。

[**明月湖国际智能产业科创基地（重庆）**](https://www.cqiip.cn/)**：** 由重庆两江新区与李泽湘团队共同发起，是XbotPark在西部的重要布局，聚焦智能硬件、新能源、智慧出行等方向，提供创业训练营、研发制造、创业孵化和产业资源。

**XbotPark宁波基地、常州基地：** 将松山湖的硬科技孵化模式拓展至长三角，结合当地制造业、高校和供应链资源支持创业团队。

**XbotPark北京基地（亦庄）：** 2026年正式落地，重点服务AI终端、具身智能及硬科技创业。基地规划超2.3万平方米办公空间，首期配置700平方米研发实验室及3600平方米共享工厂，支持产品从打样到小批量试制。

### 4.3 在李泽湘体系中我需要付出什么？可以得到什么？

以深科创为例，笔者听说李泽湘体系入孵能提供几万元的入孵费（官网说法是潜力团队 50 万以上）以及后面不断的工资收入，深科创的探索资金和后期创业投资占股 10% 原始股份。同时深科创会提供系统性的创业培训给初创团队，也会提供场地、实验室等等支持。

## 五、以陆奇为代表的奇绩创坛体系

### 5.1 陆奇是谁？

陆奇是**奇绩创坛创始人、前Y Combinator中国创始人兼CEO**，本科和硕士毕业于复旦大学，后获得卡内基梅隆大学计算机科学博士学位。他曾先后担任雅虎执行副总裁、微软全球执行副总裁、百度集团总裁兼首席运营官，是少数曾在中美互联网巨头担任核心管理职位的华人技术高管。

2018年，陆奇受时任Y Combinator（全球最大的孵化器）总裁Sam Altman邀请，创立并领导**YC中国**，同时担任YC研究院院长。2019年YC结束中国业务后，他带领团队独立创立**奇绩创坛**，将硅谷Y Combinator的早期投资和创业加速模式引入中国。

根据奇绩创坛官网公布的数据，其创业营已累计投资加速**612个早期项目**，涉及人工智能、机器人、企业软件、商业航天等38个技术领域，所投项目累计估值约**900亿元人民币**。

### 5.2 奇绩创坛是什么机构？

奇绩创坛的运作方式与美国Y Combinator颇为相似。它会从大量申请者中挑选具有潜力的创始团队，每年孵化 100 家企业进行股权投资（每个团队 30 万美金），再让团队参加约三个月的集中创业加速。到了Demo Day，奇绩会邀请全国或者全球最大的那些投资机构和天使投资人，团队可以向大量投资人展示自己的产品及阶段成果，看能否吸引更多投资。

### 5.3 最关心的问题：奇绩到底给多少钱？

根据奇绩创坛目前公开的标准投资条款：**30万美元或等值人民币的股权投资，换取公司7%的股权。**还承诺每个项目平均获得约100小时一对一辅导，Demo Day也可接触大量投资人。

**MiraclePlus Compute**。

单个项目最高可获得价值**100万元人民币的算力额度**，支持远程使用。听朋友说主要从中关村某些地方收集闲置的算力然后统一免费发放出去，但是也必须提交申请。下面是官网一些条例，看着确实很吸引人：

- 算力支持免费。
- 不要求企业股权。
- 不强制要求论文署名致谢。
- 不要求研究项目一定成立公司。
- 需要遵守资源使用规定，并定期提交简短进展。
- 如果项目未来商业化，机构希望有机会优先探讨投资和加速合作。

假如你在做 AI 相关领域的科研，你会知道我所说的 A 卡和 H 卡对于我们的科研项目有多么重要……

## 六、结语：了解创业，不意味着必须创业

回到最开始时提出的问题，相信读者也都有了自己的答案，科技创业富有富的打法，穷也有穷的打法，千万不要仅仅因为家庭条件不好就局限住自己的思维，去盲目给自己“创业”的想法判死刑，假如大家在最有活力的年纪就在脑海中将“创业”的选项直接排除，这会是非常令人遗憾与可惜的事情。

好了，以上的所有信息，是笔者借助AI搜索引擎、公开资料，以及近一年与大量创业者、Hacker、投资人交流后的经验凝练而成。大家自行辨别信息时效性和准确性，笔者不对以上任何信息担保。

写这篇文章并**不是为了鼓励大家盲目创业**，而是希望**打破信息差，让本科生知道校园之外还有哪些资源与机会。**

同时，也希望大家警惕部分权责不清的校园双创团队和课题组横向项目。不要仅仅为了所谓的项目经历，就长期承担没有合理报酬、没有成果归属约定、也缺乏实际成长价值的工作。即使是低年级甚至刚入学的新生，**我们的时间、技术能力和劳动成果同样有价值。**

考研、保研、考公、就业都是值得考虑的道路，但不应成为我们想象中的全部可能。

**了解更多选择，不是为了否定任何一条道路，而是为了让选择真正成为选择。**
